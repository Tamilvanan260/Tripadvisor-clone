# Tripadvisor Clone 🌍

A front-end website inspired by Tripadvisor, built using HTML and CSS. This project recreates a travel discovery experience where users can explore destinations, view travel images, and discover places to visit.

## 🚀 Features

- **Navigation Bar** – Easy navigation between website sections.
- **Search Section** – A travel-inspired search interface.
- **Travel Destinations** – Explore different destinations through images.
- **Image Gallery** – Display beautiful places and travel experiences.
- **Responsive Styling** – CSS styling for a clean and attractive layout.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Tamilvanan260/Tripadvisor-clone.git
   ```

2. Open the project folder:

   ```bash
   cd Tripadvisor-clone
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
